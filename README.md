# Network Access Control List (ACL) Assignment

This project demonstrates the configuration and testing of **Network Access Control Lists (ACLs)** to control communication between different departments in a network. The project includes a completed network topology, IP configuration for multiple department PCs, connectivity testing using `ping`, router ACL configuration, and access to an HTTP server.

## Project Overview

The purpose of this project was to configure and test **Access Control Lists (ACLs)** within a network environment.

The project involved:

* Configuring IP addresses on devices in different departments
* Testing network connectivity between devices
* Configuring an ACL through the router CLI
* Restricting communication between selected departments
* Allowing the Sales department to access the **HTTP service** of a server

The departments and devices shown in the project include **IT Department Engineer 1**, **Sales Rep 1**, and **HR Associate 1**.

## Configuration Steps

1. Created and completed the network topology containing the required PCs, router, and server.

2. Configured IP addresses on the **IT Department Engineer 1 PC**.

3. Configured IP addresses on the **Sales Rep 1 PC**.

4. Configured IP addresses on the **HR Associate 1 PC**.

5. Tested connectivity by sending a `ping` from the **HR Associate 1 PC** to the **IT Department Engineer 1 PC**.

6. Tested communication from the **Sales Rep 1 PC** to the **IT Department Engineer 1 PC** and observed a failed `ping`.

7. Entered the required **ACL commands** into the router CLI.

8. Configured network access rules to control communication between the departments.

9. Tested access from the **Sales department** to the HTTP service hosted on the server.

## Results and Findings

The project successfully demonstrated the use of **Access Control Lists (ACLs)** to control network communication.

The documented results show that:

* The **HR Associate 1 PC** was able to send a `ping` to the **IT Department Engineer 1 PC**.
* A `ping` from the **Sales Rep 1 PC** to the **IT Engineer 1 PC** failed.
* ACL commands were configured through the router CLI.
* The **Sales department** was able to access the **HTTP service** on the server.

These results demonstrate how ACLs can be used to implement **network segmentation and access control** by allowing or restricting specific types of network communication.
